## Integration style
- **Merge mode:** merge — commit de fusion normal, choix de JB pour garder l'historique détaillé
  (#21 et les PR Dependabot). Le kit fusionne en squash par défaut : passer
  `guarded-pr-merge.sh <PR> -- --merge --delete-branch`. Squash reste autorisé, rebase désactivé
  (`.github/repo-setup.yml`).
- **PR title convention:** pas de contrôle de titre en CI. Messages en français (`CLAUDE.md` § 4 :
  « à l'impératif » ; l'historique montre une minuscule initiale et un verbe conjugué : « rend
  l'API démontrable… », « reporte au README… »), sans préfixe Conventional Commits. Un titre de
  PR `<type>: … (#<issue>)` du kit est accepté ; les commits suivent le style du dépôt.
- **Branch naming:** `<thème>/<slug>` en français (`coffre/secrets-okms`, `vitrine/api-demontrable`) ;
  pour le kit : `<type>/<issue>-<slug>`.

## Conflict hot-spots (merge-with-main resolutions)
| File | Why it collides | Resolution |
|------|-----------------|------------|
| `package-lock.json`, `front/package-lock.json` | PR Dependabot fréquentes | **regenerate** (`npm install` / `npm --prefix front install`) |
| `Directory.Build.props`, `back/**/*.csproj` | versions de paquets NuGet (Dependabot) | prendre la version **la plus haute**, **union** des références |
| migrations EF Core (`back/Palier.Infrastructure/**/Migrations/`) | générées | **regenerate** ; deux migrations concurrentes = conflit sémantique |
| `docs/decisions.md` | journal où chaque lot ajoute une entrée Dxx | **union**, renuméroter si doublon |
| `README.md`, `docs/` | chaque lot documente ce qu'il livre | **union** |
- **Rule of thumb:** union additive files, regenerate derived files, take-the-higher for the version;
  same-logic-both-sides is a real semantic conflict — understand both intents or stop.
